# Analisis_de_empresa_de_telecomunicaciones

Este proyecto realiza un análisis exploratorio de datos (EDA) y una segmentación del comportamiento de consumo de los clientes de **ConnectaTel**, evaluando patrones de uso, demografía y calidad de los datos para generar recomendaciones estratégicas orientadas al negocio.

## 🎯 Objetivos del proyecto 

-Analizar la calidad e integridad de los datos
-Segmentar la base de clientes
-Identificar patrones de uso extremo (outliers)
-Proporcionar recomendaciones accionables

## 📂 Datasets Utilizados

El análisis se basa en tres fuentes de datos:

-`users` (Información del Cliente)
-`usage` (Consumo de Servicios)
-`plans` (Estructura Tarifaria)

## 🛠️ Etapas del Análisis Realizadas

-Exploración Inicial y Diagnóstico de Datos
-Limpieza e Integridad de Datos
-Análisis Exploratorio (EDA) y Segmentación
-Síntesis Ejecutiva y Recomendaciones
